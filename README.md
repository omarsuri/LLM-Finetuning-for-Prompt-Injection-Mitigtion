# Jatmo-Houyi-Prompt-Injection
Capstone project to explore and defend LLMs from prompt injection attacks using JATMO and HOUYI methods.
 Acknowledgments

This project includes or is inspired by the following open-source works:

- **[HOUYI: Prompt Injection Attack Against LLM-Integrated Applications](https://github.com/LLMSecurity/HouYi.git)**  
  Authors: Yi Liu, Gelei Deng, et al.  
  Source: https://github.com/LLMSecurity/HouYi.git  
  Used for black-box prompt injection techniques.

- **[JATMO: Prompt Injection Defense by Task-Specific Finetuning](https://github.com/wagner-group/prompt-injection-defense.git)**  
  Authors: Julien Piet, Maha Alrashed, et al.  
  Source: https://github.com/wagner-group/prompt-injection-defense.git 
  Used for defense modeling and training techniques.

These repositories are reused and/or adapted under their respective licenses.
